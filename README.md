# 文件管理器 v2.0

局域网文件上传下载工具，支持用户注册/登录认证。

## 功能

- 👤 **用户系统**：注册、登录、登出，密码 SHA-256 哈希存储
- 📤 **上传文件**：支持多选、拖拽上传，带进度条
- 📥 **下载文件**：登录后点击下载按钮保存文件
- 🗑️ **删除文件**：单个删除或清空全部
- 🌐 **局域网访问**：其他设备通过 IP 地址连接
- 📋 **一键复制**：点击地址自动复制到剪贴板
- 🔒 **权限控制**：未登录无法上传/下载/删除

## 使用方法

### 启动服务器

```bash
node server.js
```

启动后终端会显示访问地址：
- 本机：`http://localhost:8765`
- 局域网：`http://192.168.2.29:8765`

### 首次使用

1. 打开页面后点击**立即注册**创建账号
2. 用注册的账号登录
3. 登录后可上传、下载、管理文件

### 从另一台电脑访问

确保两台电脑在同一局域网下，浏览器打开局域网地址即可。

### 防火墙设置

如果无法访问，放行 8765 端口：

```powershell
netsh advfirewall firewall add rule name="文件管理器 8765" protocol=tcp dir=in localport=8765 action=allow
```

### 停止服务

按 `Ctrl + C`。

## 文件存储

- 上传的文件保存在 `uploads/` 文件夹
- 用户数据保存在 `users.json`（首次启动自动生成）
- 会话为内存存储，重启服务器后需重新登录

## 依赖

- Node.js（无需额外 npm 包，仅使用内置模块：http, fs, path, os, crypto）
