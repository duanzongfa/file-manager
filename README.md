# 文件管理器 v1.0

局域网文件上传下载工具，无需服务器部署，直接在电脑上运行即可使用。

## 功能

- 📤 上传文件（支持多选、拖拽）
- 📥 下载文件
- 🗑️ 删除单个或多个文件
- 🌐 局域网访问（其他设备通过 IP 地址连接）
- 📋 一键复制局域网地址

## 使用方法

### 启动服务器

```bash
node server.js
```

启动后终端会显示：
- 本机访问地址：`http://localhost:8765`
- 局域网访问地址：`http://192.168.2.29:8765`（或其他 IP）

### 从另一台电脑访问

确保两台电脑在同一局域网下，在浏览器地址栏输入上面显示的局域网地址即可。

### 防火墙设置

如果无法访问，需要放行 8765 端口：

```powershell
netsh advfirewall firewall add rule name="文件管理器 8765" protocol=tcp dir=in localport=8765 action=allow
```

### 停止服务

按 `Ctrl + C` 停止服务器。

## 文件存储

上传的文件保存在 `uploads/` 文件夹中。

## 依赖

- Node.js（无需额外安装任何 npm 包，使用内置模块）
